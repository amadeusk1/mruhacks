# Engine Specs: Index

Work from the concept sheets that belongs in **Godot, not in models**: particles, shaders, timing, triggers and gameplay-driven motion. Each spec lists what the art pack already provides (meshes, sockets, parts, clips) and exactly what the engine must build.
