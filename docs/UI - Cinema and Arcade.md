## Behavior and implementation notes

Movie titles and artwork are fictitious samples; label demo sources explicitly in implementation. Add library search and selected-title metadata. Host-only controls are disabled for nonhosts; show host transfer, buffering and reconnect status. Keep movie and voice volume independent. Two penguins use two stations on one cabinet. Puck Rally remains the proposed genre; generated Ice Smash labeling is not a title decision. Back to town should first release the slot; it does not authorize automatic travel.

Waddle World is the user-selected placeholder title. These are raster UI concepts, not implemented Godot scenes. World art, player proportions, example data, keys and menus shown are illustrative; the original penguin model reference remains authoritative.
