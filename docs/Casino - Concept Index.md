## Art review notes

Use cream stone, snow-dusted coral roofs, teal felt/trim, walnut and restrained brass. Reuse established lanterns, planters, seats and modular penguin rig where possible.

Generated details are visual guidance only: roulette numerals/colors/pocket order and betting grid are not accurate enough to ship; redraw from the selected rules. Seat counts differ between some hero and overhead views; create explicit seat sockets from the chosen gameplay capacity. The roulette sheet's approximate 40 cm scale annotation is not canonical. The shared-animation sheet uses different slot symbols from the slots kit: use the slots kit's fish/snowflake/star/footprint family consistently. Poker UI shows check and call together; only enable legal actions from server state. Generated branding is exploratory, not a new logo decision.

Concepts use play chips. Acquisition, persistence, transferability and any connection to the wider economy are not decided. No purchases or redemption system is specified.
