## Behavior and implementation notes

Timers, team sizes and score limits are proposed examples. Snowball Ready dots must not imply limited ammunition when using the proposed unlimited-snowball rules; use a cooldown indicator instead. Use different team icons or labels as well as colors. Basketball target band needs an explicit visual marker and accessible feedback. Time trial and shooting contest are initial proposals, not a rejection of races or full basketball. Keep camera consistent with the actual game; these views are UI staging.

Waddle World is the user-selected placeholder title. These are raster UI concepts, not implemented Godot scenes. World art, player proportions, example data, keys and menus shown are illustrative; the original penguin model reference remains authoritative.
