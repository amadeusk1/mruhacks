## Existing exports to reuse

Folders: `buildings / cottage / home_themes / room_kit`. Basic wall/roof/door/floor modules, cottage, themed furniture and decoration exports exist.

Existence is verified from filenames only; it does not mean every model is art-approved, rigged, or integrated.

## Remaining kit scope

Six alternative shell families: snow dome, A-frame, round cottage, treehouse, lighthouse loft, houseboat. Curved walls/floors, matching roofs, tree support, hull/deck, stairs/landing and door/window adapters. No homes export folder was found in this snapshot.

## Authoring and integration

Use valid floor-cell masks for curved interiors. Separate structure and decorations. Shell selection and grid decoration are in scope; arbitrary player structural building is not implied by the sheet. Dimensions in art are illustrative, not final measurements.

Keep each reusable piece separate, use recolorable materials where appropriate, reserve clear collision/interaction space, and provide a manifest with footprint, pivot, sockets and material roles. Generated labels and staged assemblies are visual references, not exact implementation instructions. All character scale references must use the original penguin proportions.
