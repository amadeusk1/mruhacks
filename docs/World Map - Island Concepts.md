## Shared layout

Central fountain plaza with cafe, cinema and arcade; sledding hill northwest; snowball arena northeast; homes west; sketch club east; fishing docks southwest; basketball southeast. A stream, bridges and looping paths connect the districts.

Use the overhead sheet for layout discussion and the angled overview for visual mood. Exact scale, traversal times, collision, entrances and housing instance transitions still need in-engine validation. Cottage count and decorative details are illustrative.

## Generation

Created with the built-in image generation tool. The overview uses the supplied island mockup as a visual reference; the overhead image is a separate generation to improve camera angle. Exact prompts are in [World Map - Generation Prompts](World%20Map%20-%20Generation%20Prompts.md).
