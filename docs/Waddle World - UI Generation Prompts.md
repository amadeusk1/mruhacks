# Waddle World - UI Generation Prompts

Tool: built-in image generation. Twelve new boards saved in `Images/UI - ...png`, linked in [Waddle World - UI Mockups](Waddle%20World%20-%20UI%20Mockups.md). Shared direction: original simple ivory/navy/teal/coral UI, readable rounded controls, low-poly snowy penguin village, no ornate framing or monetization. Per-board prompt directions:

## UI - Main Menu and Entry

Board MAIN MENU & ENTRY. Panel MAIN MENU: WADDLE WORLD large rounded navy wordmark over snowy seaside penguin town, prominent Play button, small Settings button, Quit discreet. Panel YOUR PENGUIN: large round blue penguin preview, display name field 'Snowdrop', six color swatches, Continue and Back, no account password. Panel CHOOSE A WORLD: simple three-row list Snowcap 18/40, Cozy Cove 12/40, Frosty Pier 40/40 with Full disabled; selected Snowcap, Join button, Refresh. Panel JOINING: small penguin footprints loading illustration, 'Joining Snowcap…', Cancel button, minimal background. Server names/capacities illustrative.
