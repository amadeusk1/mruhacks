# Pengloo Party
Working title for a cozy multiplayer penguin town built in Godot.

- [Developer handoff](docs/Dev%20Handoff%20-%20Start%20Here.md) — requirements, current-code observations, server architecture, persistence, activity specifications, deployment and test plan.
- [UI mockups](docs/Pengloo%20Party%20-%20UI%20Mockups.md) — 12 boards / 48 primary screen concepts.
- [Design and art index](docs/README.md) — original brief, assets, concepts and integration notes.

Open `project.godot` with the pinned project-compatible Godot version. See the handoff's baseline findings before assuming a clean runtime build. The current repository contains prototype gameplay and networking; documentation distinguishes implemented evidence from proposed systems. No online backend was deployed as part of the mockup/documentation work.
