Your next stop: the island

  1. Download the build for your computer and extract the whole archive. On Android, download the APK and open it. If your phone asks, allow the browser to install apps.
  2. Open Pengloo Party, then press Play and choose your penguin.
  3. Choose Pengloo Party → Join world. The app connects to our online server automatically.

Keep the app, game data and included libraries together. Online play needs an internet connection. Practice Island is solo play.

Host a server

Run your own island and it shows up automatically in everyone's Servers list, in the browser and the desktop app. Players join through pengloo.party, so there's no port forwarding, domain or certificate to set up.

  1. From the desktop app: press Play, choose Host a Server, pick a name and player limit, then Start hosting.
  2. Always-on (Linux): download the server package, copy env.example to .env, set your server name, and run docker compose up -d. Its README covers running without Docker.
  3. Optional cinema: host movies from your own Emby server with your own host and viewer codes. Fill in the Cinema section in the app (and press Test connection), or cinema.env in the package. The big screen needs ffmpeg. Skip it and your cinema shows “No cinema on this server”.

Your Emby details and codes stay on your computer; only movie traffic passes through pengloo.party, with a per-server bandwidth cap. Sign-ins are per server, and the official island keeps its own codes. Servers must run the same version as pengloo.party, so update after game updates. Community servers aren't run or moderated by Pengloo Party.

Early desktop builds

These are preview builds. Windows builds are unsigned; the Mac build is ad-hoc signed and is not Apple-notarized. Your system may ask you to approve the app. If you prefer not to, you can always play in your browser.

On macOS, move the app to Applications. If blocked, review the app in System Settings → Privacy & Security. On Linux, allow the included executable to run, then open it. Windows users should extract the ZIP before opening the EXE.

Keeping everyone together

Desktop and browser players use the same public island. Downloads do not update automatically yet. If joining stops working after a game update, come back here for the latest build.

Local settings and saves are not cloud-synced accounts. Voice, cinema and platform-specific features are still being tested across desktop systems.
